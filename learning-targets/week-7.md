## Week 7 – Learning Targets

### Java Syntax and Core Language Fundamentals
1. I can explain how Java source code is organized into classes and files.
2. I can declare variables, methods, parameters, and return types using correct Java syntax.
3. I can use conditionals, loops, and collections to implement basic program logic in Java.
4. I can compile and run simple Java programs and interpret compiler errors at a practical level.
5. I can distinguish between primitive types, reference types, and object instances.

---

### Classes and Objects
1. I can define classes with fields, constructors, and methods that model simple domain concepts.
2. I can create objects from classes and use instance methods to represent behavior.
3. I can explain the relationship between a class definition and instantiated objects.
4. I can design small classes with clear responsibilities instead of mixing unrelated behavior.

---

### Object-Oriented Principles
1. I can explain abstraction, encapsulation, inheritance, and polymorphism in concrete programming terms.
2. I can use access modifiers to control what is exposed or hidden in a class design.
3. I can create inheritance relationships when they improve clarity and reuse.
4. I can use method overriding and interface-style behavior to support polymorphism.
5. I can explain when composition is preferable to inheritance in a simple design.

---

### SOLID Foundations
1. I can explain each SOLID principle at a beginner-friendly, code-focused level.
2. I can identify examples of classes that violate single responsibility or create unnecessary coupling.
3. I can refactor basic designs so responsibilities are more clearly separated.
4. I can explain how better object-oriented design improves maintainability and testability.

---

### Java Problem Solving and Testing Readiness
1. I can implement small Java programs that model data and behavior cleanly.
2. I can reason about how object design affects future API or service-layer work.
3. I can read existing Java class code and explain what responsibilities it currently owns.

---

### JUnit Fundamentals
1. I can write and run JUnit tests for small Java classes and methods.
2. I can structure tests using clear arrange-act-assert flow and readable test names.
3. I can use assertions to verify expected outputs, state changes, and error conditions.
4. I can distinguish between testing behavior and testing implementation details in Java code.
5. I can use unit tests to validate object-oriented designs before integrating them into larger backend applications.

---

### Intro to Design Patterns
1. I can explain the purpose of a design pattern as a reusable solution to a recurring design problem.
2. I can identify when a simple pattern such as Strategy, Factory, or Adapter can improve code organization and flexibility.
3. I can distinguish between helpful use of a pattern and unnecessary overengineering.
4. I can relate design patterns to object-oriented principles such as composition, abstraction, and separation of responsibilities.

---

### API Documentation with Swagger
1. I can explain the purpose of Swagger/OpenAPI in documenting and communicating a backend API.
2. I can use generated API documentation to inspect available endpoints, request shapes, and response models.
3. I can verify backend endpoint behavior using Swagger-based API exploration tools.
4. I can explain how API documentation supports frontend integration, testing, and team collaboration.
5. I can define an API contract in an OpenAPI specification and generate typed interfaces or client models from that contract for safer frontend-backend integration.
