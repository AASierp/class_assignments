# JavaScript Core Practice

## Assignment

Create a simple task-list application.

The page must contain:

- A text input
- A priority select input
- An Add Task button
- A task count
- A list of tasks

Store tasks in an array. Each task should be an object containing:

- A task name
- A priority
- A completion status

Your application must:

1. Select page elements with `document.querySelector`.
2. Listen for the form's `submit` event.
3. Prevent the page from refreshing.
4. Read the user's input.
5. Add a task object to the array.
6. Loop through the array.
7. Create and display list items.
8. Update the task count.
9. Use a function with parameters and a return value.
10. Use a conditional to display different text based on priority.

## Questions

1. What is the difference between `let` and `const`?
2. What is an array?
3. What is an object?
4. What is a function parameter?
5. What is a return value?
6. What does `event.preventDefault()` do?
7. What does an event listener do?
8. Why does the task list disappear after refreshing the page?

## Extension

Add a button that marks a task complete or deletes it.
