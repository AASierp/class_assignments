# HTML Structure and Semantics Practice

## Assignment

Create an `index.html` file for a small workshop webpage.

Your page must include:

- A valid HTML document structure
- A `<header>`
- A `<nav>`
- A `<main>`
- At least two `<section>` elements
- A `<footer>`
- One ordered or unordered list
- One link
- One table
- One image with alternative text
- One form containing:
  - A text input
  - An email input
  - A select input
  - A checkbox or radio button
  - A submit button

Use labels for every form control.

## Questions

1. What belongs inside `<head>`?
2. What belongs inside `<body>`?
3. Why are semantic elements preferable to using only `<div>` elements?
4. Why should form inputs have labels?
5. Why should images have alternative text?
6. When should a table be used?
7. Why should heading levels follow a logical order?
