# Web Fundamentals Practice

### Learning Target
> I can explain how browsers and servers communicate and use browser developer tools to inspect a web page.

## Assignment

1. Open `https://example.com` in a browser.
2. Identify the protocol, domain, and path in the URL.
3. Open browser developer tools.
4. In the **Elements** tab, locate:
   - `<html>`
   - `<head>`
   - `<body>`
   - A heading
   - A paragraph
   - A link
5. Temporarily change the heading text or color.
6. Refresh the page and observe what happens.
7. Open the **Network** tab and refresh the page.
8. Record:
   - Request URL
   - Request method
   - Status code
   - Response content type
9. Use the **Console** to read and change the heading text.

## Questions

1. What happens after a user enters a URL?
2. What is the difference between a browser and a server?
3. What is an HTTP request?
4. What is an HTTP response?
5. What does a `200` status code mean?
6. Why are changes made in developer tools not permanent?
7. What roles do HTML, CSS, and JavaScript play on a webpage?

## Extension

Find one HTML, CSS, JavaScript, image, or API request in the Network tab and explain its purpose.
