# CSS Layout and Styling Practice

## Assignment

Create a webpage containing:

- A header with navigation
- A main content area
- At least three cards
- A footer

Create a separate `styles.css` file.

Your CSS must demonstrate:

- `box-sizing: border-box`
- Element selectors
- Class selectors
- A hover or focus state
- Padding, borders, and margins
- A reusable container class
- A flexbox layout
- A grid layout
- Consistent typography and spacing
- A responsive media query

Use browser developer tools to inspect one card's box model and identify:

- Content
- Padding
- Border
- Margin

## Questions

1. What is the difference between a class selector and an element selector?
2. What is the CSS box model?
3. What is the difference between margin and padding?
4. When is flexbox useful?
5. When is grid useful?
6. What does `box-sizing: border-box` do?
7. What does a media query do?
8. How can developer tools help diagnose an overridden CSS rule?

## Extension

Intentionally introduce a broken or overridden CSS rule, then document how you found and fixed it.
