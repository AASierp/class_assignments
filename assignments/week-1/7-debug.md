# JavaScript Debugging Practice

## Assignment

This assignment is to give you some exposure into using a debugger to handle unexpected behavior from your code. In this case, you're debugging code you didn't write (an LLM did), but you will nonetheless get good practice developing skills with the tool.

Using debug.html and debug.js, use VSCode's Run & Debug function to identify the following bugs:
1. A syntax error
2. A misspelled DOM selector
3. An incorrect event type
4. A string that should be converted to a number
5. A conditional placed in the wrong order
6. An incorrect object property name

For each bug, record:

Use:

- `console.log`
- `console.error`
- The browser stack trace
- At least one breakpoint
- Step over
- Step into

## Questions

1. What is a syntax error?
2. What is a runtime error?
3. What is a logic error?
4. What information does a stack trace provide?
5. Why might `document.querySelector` return `null`?
6. Why are input values returned as strings?
7. What is the difference between logging and using a breakpoint?
8. What is the difference between step over and step into?

## Extension

Ask another learner to introduce three bugs into the application. Diagnose each without being told where the bugs are.
