# React Front End – Calendar Application

Hello,

I’m writing to request that you create a custom calendar application for me. The existing market solutions are too complex and integration dependent. I want a simple, intuitive website where users can sign up, manage their schedules, and collaborate by inviting others to events.

## Feature Requirements

### Account Management
- Sign up with email, password, and name
- Log in / log out of an account
- Edit profile details: name, email, password

### Event Management
- Create events with title, description, date/time, and location
- Edit events you’ve created
- Delete events you’ve created
- View event details

### Invitations & RSVPs
- Invite one or more registered users to an event
- Accept or decline event invitations
- See list of attendees and their RSVP status

## Pages / Views

The front end should support an appropriate number of pages to accomplish the requirements above.

Additionally, users should be able to input a date range to view a list of events within that range.

Please include any views or pages that would be appropriate given the project and timeline.

## Requirements

### Languages & Frameworks
- React
- TypeScript
- HTML & CSS

- `vite`
- `json-server`

- All persistent data shall be in a single `db.json` file
