# Thrivent Full-Stack Cohort

## Overview
This cohort is a hands-on introduction to modern **full-stack software development**. The curriculum progresses from **Git, HTML, CSS, and JavaScript** into **TypeScript, React, Next.js, SQL, GraphQL, Java, Spring**, and finally **full-stack deployment and capstone delivery**.

The focus is on building practical technical skills, learning how frontend and backend systems connect, and developing habits used by collaborative software teams. You will learn by building, testing, communicating clearly, and reflecting on your progress.

---

## Curriculum Flow

- **Weeks 1-2: Foundations**
  - Git and version control
  - HTML, CSS, JavaScript
  - TypeScript fundamentals
  - Reusable types and test-driven development

- **Weeks 3-4: Frontend Development**
  - React fundamentals
  - Props, state, hooks
  - React with TypeScript
  - Frontend testing
  - CI/CD basics with GitHub Actions

- **Weeks 5-6: Next.js and Data**
  - Next.js routing and rendering
  - Data fetching and configuration
  - SQL fundamentals
  - GraphQL fundamentals
  - REST and GraphQL integration from the frontend

- **Weeks 7-8: Backend Development**
  - Java syntax and object-oriented programming
  - SOLID principles
  - Spring fundamentals
  - REST API development
  - JPA and JDBC persistence

- **Weeks 9-12: Full-Stack Integration and Capstone**
  - Frontend/backend integration
  - Deployment across the stack
  - Team workflow and delivery planning
  - Capstone implementation
  - Demo preparation, hardening, and final presentation
  - Reflection and portfolio readiness

---

## Daily Schedule

- **Stand-up + morning lecture**
  - Recap previous work
  - Share blockers and questions
  - Introduce new concepts

- **Break**

- **Afternoon lecture / guided support**
  - Review practice issues
  - Cover additional concepts
  - Walk through examples

- **Technical communication practice**
  - Explain a concept, workflow, or implementation clearly

- **Journal writing and reflection**
  - Record progress
  - Note challenges
  - Ask at least one technical question

---

## Expectations
Cohort members are expected to:
- Attend sessions prepared and on time
- Participate actively in lectures, exercises, and discussions
- Ask questions early when blocked
- Attempt problems independently before escalating
- Communicate clearly about technical decisions and issues
- Collaborate respectfully with teammates
- Treat testing, deployment, and code quality as part of the work, not as optional cleanup

---

## Technical Emphasis
This cohort emphasizes:
- Incremental delivery
- Type safety
- Testing and verification
- Clear API contracts
- Maintainable frontend and backend design
- Practical deployment workflows
- Team-based software delivery
